# Reuse status

No open-source code or data license is selected for this initial package.
This file is a status disclosure, not a new license or a vendor permissions grant.
The owner has confirmed relevant data-use and publication permissions; the right
to grant broader downstream code/data reuse has not been documented here.

The initial package contains authored documentation and reviewed aggregate
results. Underlying historical prices, event-level datasets, detector source,
third-party implementations and private infrastructure are not distributed.
Their reuse permissions must not be inferred from these summaries. A future
license decision must identify the material covered and the corresponding rights.
